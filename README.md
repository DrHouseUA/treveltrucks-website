TrevelTrucks — це Next.js вебсайт з директорією app, розгорнутий на Vercel. Мета — швидкий, адаптивний промо-сайт із чистою архітектурою та зрозумілою навігацією для представлення послуг і портфоліо компанії.

Основні функції
• 	Головна сторінка: Редагується у файлі , з автооновленням під час розробки.
• 	Ви змінюєте контент прямо в app/page.tsx; результат бачите одразу у браузері.
• 	Шрифти та оптимізація: Використання  для автоматичного завантаження сімейства Geist від Vercel.
• 	Це забезпечує коректне завантаження шрифтів і покращує продуктивність без ручної конфігурації.
• 	Типізація: Основна мова — TypeScript, стилі — CSS.
• 	За статистикою репозиторію: TypeScript ~67.7%, CSS ~31.6%.
• 	Деплой: Публічний домен на Vercel — treveltrucks-website.vercel.app.
• 	Готовий продакшн-білд доступний за прямим посиланням на Vercel.

Інсталяція та запуск
Попередні вимоги
• 	Node.js: 18+
• 	Пакетний менеджер: npm, pnpm, yarn або bun
Клонування та встановлення
1. 	Клонувати репозиторій:
git clone https://github.com/DrHouseUA/treveltrucks-website.git
2. Перейти до каталогу:
cd treveltrucks-website
3. Встановити залежності:
npm install
# або:
yarn install
pnpm install
bun install
